## 核心能力与架构特性

<CardGrid stagger>
	<Card title="纯出站零端口暴露接入" icon="rocket">
		被控开发机或云服务器无需开放任何入站 TCP 端口、无需配置 SSH 密钥转发。节点通过一行 `install.sh` 命令注册为用户级守护服务，主动出站建立受控加密隧道。
	</Card>
	<Card title="多工作树与多会话并行" icon="puzzle">
		围绕 `Project → Task → Worktree → Conversation → Session` 组织研发全生命周期，在同一控制面同时驱动多台机器上的 Claude、Codex 等原生 Agent CLI。
	</Card>
	<Card title="执行机权威文件与实时流" icon="document">
		代码始终留在被控机本地磁盘，不向控制面同步整仓副本；文件树、Git Diff、终端输出与运行时增量事件经统一信封实时推送到 Web 与 macOS 桌面客户端。
	</Card>
	<Card title="断线自愈与防串机保护" icon="approve-check-circle">
		网络抖动或控制面重启不会中断被控机上已受理的编码回合，重连后自动按游标续传；目标主机离线时明确报错，绝不静默改投到其他机器。
	</Card>
</CardGrid>
